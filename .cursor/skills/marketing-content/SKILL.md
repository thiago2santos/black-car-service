# Marketing Content

## Use this skill for

- one-pagers
- pitch structure
- offer articulation
- sales scripts
- landing page copy
- email or WhatsApp outreach
- message hierarchy for campaigns

## Do not use this skill for

- primary market research design
- legal or labor compliance interpretation
- HR policy drafting

If the main deliverable is validation, interviews, benchmark, or evidence gaps, prefer the research-focused skill first.

## Default workflow

1. Identify the asset:
   - pitch
   - one-pager
   - campaign
   - outreach
   - institutional page
2. Define the audience and desired action.
3. Extract the core promise, proof, and objection barrier.
4. Write with concrete language and controlled claims.
5. Flag unsupported claims as hypotheses or placeholders.

## Mandatory questions when context is weak

- Who is the audience?
- What action should this asset generate?
- What proof points already exist?
- What tone should dominate: institutional, consultative, direct, or premium?

## Preferred outputs

### Message map

```markdown
## Audience

## Core problem

## Value promise

## Proof points

## Main objections

## Suggested language
```

### One-pager structure

```markdown
## Headline

## Problem

## Solution

## Why trust this offer

## Operational scope

## Call to action
```

### Outreach draft

```markdown
## Goal

## Opening

## Relevance hook

## Offer or next step

## CTA
```

## Working rules

- Prefer clarity over flourish.
- Avoid inflated adjectives without evidence.
- Keep differentiation tied to operations, proof, or buyer pain.
- Write for decision-making, not for decoration.
- When evidence is thin, use cautious language.
- If the user questions whether the claim itself is true, validate the claim before polishing the wording.

## Examples

### Example prompts

- "Transforme esse diagnostico em um one-pager comercial."
- "Refine esse pitch para um gestor administrativo."
- "Escreva uma mensagem curta de prospeccao com tom premium enxuto."

### Example response stance

Do:

- adapt language to the buyer role
- preserve operational credibility
- remove vague jargon

Avoid:

- inventing numbers, cases, or guarantees
- using generic luxury language detached from the offer
