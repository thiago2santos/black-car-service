# Canais

## Papel desta area

Esta area concentra os ativos e as implementacoes tecnicas dos canais da C-Level Mobility.

Aqui devem viver:

- site institucional
- landing pages
- canal de WhatsApp
- e-mail
- trafego pago
- automacoes ligadas aos canais

## Regra de fronteira

Se o tema for mensagem, oferta, SEO, campanha ou objetivo comercial, o arquivo deve ficar em `1.comercial/`.

Se o tema for codigo, pagina, asset, integracao ou execucao tecnica do canal, o arquivo deve ficar em `4.canais/`.

## Regra especifica para automacoes

`4.canais/automacoes/` existe apenas para implementacao tecnica.

Aqui entram:

- integracoes
- webhooks
- scripts de execucao
- fluxos automatizados
- infraestrutura tecnica de canais

Aqui nao entram:

- estrategia
- brief
- objetivo comercial
- hipotese
- criterio de sucesso

Esses itens devem ficar em `1.comercial/`.
