# Planilhas Financeiras

## Objetivo

Centralizar planilhas ativas de apoio financeiro e comercial da C-Level Mobility.

## Arquivos

- `planilha-cotacao-yaris.ods`: modelo operacional de cotação ligado ao script `scripts/gerar_planilha_cotacao_yaris.py`

## Regra

- planilhas ativas devem ficar nesta pasta
- planilhas sem papel claro ou legadas devem ir para `arquivo/soft-delete/`
